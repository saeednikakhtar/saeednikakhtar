## Selected work

### VARDLYX / Orbita
Onboard safety and digital identity for unmanned aircraft: local rules, geofences, flight-controller integration and operator tools.

[Project overview, recordings & documents →](https://robtk.com/files1/vardlyx-materials-ru.html?lang=en)

### RESCUE Flight Lab
An ArduPlane 4.6.3 project combining a custom RESCUE flight mode, native Windows SITL, QGroundControl integration and a telemetry-driven web panel. The repository includes source changes, repeatable simulation scenarios, original flight logs and documented verification.

[Source & Windows releases](https://github.com/saeednikakhtar/rescue-flight-lab) · [English presentation](https://saeednikakhtar.github.io/rescue-flight-lab/en/)

### RESCUE — Core Firmware
A focused companion repository containing the firmware patch, modified C++ sources, complete parameter profile, compiled SITL and original BIN evidence.

[Firmware & technical documentation →](https://github.com/saeednikakhtar/rescue-core-submission)

> RESCUE verification covers native software-in-the-loop simulation. It does not establish physical flight-controller or real-parachute qualification; test scope and remaining work are documented in the project.
