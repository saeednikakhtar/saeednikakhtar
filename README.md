## Selected work

### VARDLYX / Orbita — Onboard UAV Systems
I lead technical development at Robotics Innovation, connecting onboard safety rules and geofences with flight-controller integration, telemetry and operator tools. Orbita is the earlier flight-computer project; VARDLYX continues its development around onboard safety and digital identity.

The public case study brings together system architecture, product demonstrations, flight recordings and remote-identification test documentation.

[Project case study, recordings & documents →](https://robtk.com/files1/vardlyx-materials-ru.html?lang=en)

### RESCUE Flight Lab
An ArduPlane 4.6.3 project combining a custom RESCUE flight mode, native Windows SITL, QGroundControl integration and a telemetry-driven web panel. The repository includes source changes, repeatable simulation scenarios, original flight logs and documented verification.

[Source & Windows releases](https://github.com/saeednikakhtar/rescue-flight-lab) · [English presentation](https://saeednikakhtar.github.io/rescue-flight-lab/en/)

**Core firmware:** the [companion repository](https://github.com/saeednikakhtar/rescue-core-submission) contains the C++ patch, parameter profile, compiled SITL, original BIN evidence and build documentation.

### Rusifa — Russian Language School
A Russian-learning platform for Persian speakers, with a right-to-left web interface, structured lessons, audio dialogues, flashcards, quizzes and graded reading. It brings together self-paced study, teacher-led classes and learner-progress workflows, with an Android app available from the public website.

[Explore the live school →](https://learnrussian.robtk.com/russianlearin)
